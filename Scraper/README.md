# Books to Scrape Scraper

A sandbox scraper for practicing data collection ethics and techniques.

## Target Classification

- **Site**: Books to Scrape (`https://books.toscrape.com/`)
- **Why**: This is a dedicated sandbox site built for practicing web scraping. All data (prices, ratings, titles) is fictitious [citation:3][citation:10].
- **Scope**: First 3 catalogue pages only (page-1.html, page-2.html, page-3.html).
- **Data collected**: Book title, price, availability, rating, and product URL.
- **Appropriateness**: This site explicitly invites scraping practice, making it the ethical and legal starting point for this assignment.
